# Atividades 31/08 — Estruturas de Dados e Análise de Algoritmos

Lista de exercícios em Java, todos em um único arquivo com menu interativo.

## Exercícios

1. Imprimir de 1 até N
2. Somar de 1 até N
3. Maior e menor de 20 números
4. Urna eletrônica
5. Exponenciação
6. Verificar número primo

## Como executar

No Windows, basta rodar o `Compilar e Rodar.bat` (ajuste o `JAVA_HOME` dentro dele para o seu JDK).

Ou pelo terminal:

```bash
javac Exercicios.java
java Exercicios
```

## Validação de entrada

- `lerInteiro()` — aceita qualquer inteiro e rejeita letras/símbolos
- `lerInteiroMinimo(min)` — além disso, exige valor `>= min` (barra negativos)
